# 🧊 Онлайн-холодильник — Telegram-бот

Бот запоминает, что лежит у вас в холодильнике, и по короткому опросу предлагает
**случайное блюдо**, которое реально из этих продуктов приготовить.

## Функционал

1. **Онлайн-холодильник** — пользователь перечисляет продукты (через запятую или
   построчно), бот их запоминает (SQLite — данные переживают перезапуск).
   Распознаются синонимы: «картошка» → картофель, «курочка» → курица,
   «греча» → гречка, «шампиньоны» → грибы и т.д.
2. **Подбор блюда — пошаговый опрос:**
   1. 🥩 Какую еду предпочитаем? (мясо / рыба / крупы / овощи / суп / сладкое / любая)
   2. 🥗 Нужна ли диета? Если да — какая и **на какой период** (в днях; срок
      хранится в БД и автоматически «сгорает» по истечении).
   3. 👨‍🍳 Сложность приготовления **по умению и времени** (просто / средне / сложно).
   4. 😋 Чего хочется конкретно сейчас? (мясо, крупа, овощи… или «на твой вкус»)
3. На основе ответов бот фильтрует базу из ~37 блюд по наличию продуктов
   (процент покрытия ингредиентами), диете, сложности и пожеланию — и выдаёт
   **случайное** подходящее блюдо с указанием: сколько нужно времени, что уже есть
   в холодильнике, чего не хватает. По кнопке/слову «Ещё» — новый случайный вариант
   без повторов.

## Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | сам бот (aiogram 3): клавиатуры, состояния диалога, SQLite |
| `dishes.py` | база блюд и справочники (категории, диеты, сложности) |
| `fridge_logic.py` | парсинг продуктов, матчинг ингредиентов, подбор и рандом |

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен от @BotFather"
python bot.py
```

Необязательные переменные окружения: `DB_PATH` (по умолчанию `fridge.db`).

## Команды и кнопки

- `/start` — меню; `/add` или «➕ Обновить продукты» — внести продукты
- `/fridge` / «🧊 Мой холодильник» — посмотреть список
- `/clear` / «🗑 Очистить холодильник» — очистить
- `/cook` / «🍳 Что приготовить?» — начать опрос; «Ещё» — новый вариант
- `/diet` — активная диета и её срок; `/help` — справка

## Как подбирается блюдо

Для каждого блюда считается **покрытие** = доля ингредиентов, найденных в
холодильнике. В выборку попадают блюда с покрытием ≥ 60 %, подходящие по категории,
диете и уровню мастерства (берутся блюда *не сложнее* запрошенного уровня).
Случайный выбор — взвешенный по покрытию. Если точных совпадений нет, требования
плавно смягчаются (сначала без «хотелки», потом без диеты, порог покрытия ниже),
и бот честно помечает предложение как «самое близкое».

## Расширение базы

Добавьте словарь в список `DISHES` в `dishes.py` — логика подбора подхватит его
автоматически.
